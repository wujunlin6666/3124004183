# 论文查重系统

## 项目名称

基于 Python 的论文查重算法设计

## 学号

3124004183

## 项目简介

本项目实现一个论文相似度检测系统。
程序通过命令行参数读取原论文和待检测论文，
计算两篇论文之间的重复率，并将结果输出到指定文件。

## 项目结构

main.py                 程序入口

plagiarism_checker.py   查重算法核心模块

file_utils.py           文件读写模块

tests/                  单元测试

test_files/             测试数据
