## 三、设计与实现

### 3.1 模块划分

结合 `README.md` 介绍 `expression`、`generator`、`parser`、`service`、`cli` 五个模块。可画出下面的关系：命令行 → 服务层 → 生成器/解析器 → 表达式树。

### 3.2 关键算法

1. 用 `Fraction` 精确计算，避免浮点误差。
2. 用表达式树保存括号和运算顺序。
3. 减法生成时保证左子树值不小于右子树值。
4. 除法生成时保证 `0 < 左值 < 右值`。
5. `+` 和 `×` 节点递归排序规范键，实现题目定义的去重。

粘贴少量关键代码并逐段解释，不要把整个项目源码全部贴进博客。
